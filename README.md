# NeoICQ

ICQ-клиент для Android в стиле QIP 2005. Работает по протоколу OSCAR с серверами, которые живут
и сейчас: neoicq, kicq, nina, jimm.online и другими.

Здесь только готовые сборки. Скачать последнюю версию:
**[Releases → Latest](../../releases/latest)**: файл `NeoICQ-<версия>.apk`.

## Что умеет

- Несколько аккаунтов на разных серверах, быстрое переключение
- Список контактов в стиле QIP: группы, статусы, X-статусы, «глазки» приватности, шарик дня рождения,
  определение клиента собеседника
- Сообщения, история с поиском и сохранением в txt, анимированные смайлы
- Статусы и X-статусы с текстом, приватный статус, автоотсутствие
- Поиск пользователей по серверу (UIN, ник, имя, город, пол, возраст)
- Авторизация, «Вас добавили», чтение статус-сообщений
- Русский и английский интерфейс

## Установка

1. Скачайте APK из последнего релиза.
2. Откройте файл на телефоне и разрешите установку из этого источника, если Android спросит.
3. Новую версию ставьте поверх старой: аккаунты и настройки сохранятся.

Нужен Android 9 или новее.

## Версии

- `a` в конце номера (`v0.0.32a`): альфа, идёт активная разработка, возможны ошибки.
- `b`: бета, функции почти готовы, ищем ошибки.
- Без буквы: стабильная версия.

Список изменений есть в описании каждого релиза.
