Neo IM
Мессенджер для Android в стиле QIP 2005. Работает по протоколу OSCAR с серверами, которые живут и сейчас: neoicq.ru, kicq.ru, nina, jimm.online, Mandarin и другими.

Здесь только готовые сборки. Скачать последнюю версию: Releases → Latest: файл NeoIM-<версия>.apk.

Что умеет
Несколько учётных записей на разных серверах одновременно в сети, с общим списком контактов
Список контактов в стиле QIP: группы, статусы, X-статусы, «глазки» приватности, шарик дня рождения, определение клиента собеседника
Сообщения, история с поиском и сохранением в txt, анимированные смайлы
Статусы и X-статусы с текстом, приватный статус, автоотсутствие, «Сейчас играет» из музыкального плеера
Поиск пользователей по серверу (UIN, ник, имя, город, пол, возраст)
Авторизация, «Вас добавили», чтение статус-сообщений, «Всевидящее око»
Стили интерфейса: Классический, Neo и Neo Glass; светлая, тёмная и AMOLED темы; наборы значков
Русский и английский интерфейс
Установка
Скачайте APK из последнего релиза.
Откройте файл на телефоне и разрешите установку из этого источника, если Android спросит.
Новую версию ставьте поверх старой: учётные записи и настройки сохранятся. Версии, вышедшие под старым названием NeoICQ, обновляются так же, поверх.
Нужен Android 9 или новее.
